# Инструкция по работе с заказами — сайт v1.5

Готовый одностраничный сайт для GitHub Pages. Не требует программирования, сборки или платного хостинга.

## Что внутри

- `index.html` — текст, структура и ссылки сайта;
- `styles.css` — базовая структура и оформление;
- `theme-reference.css` — тёмная тема в стиле предоставленного референса;
- `app.js` — поиск и увеличение скриншотов;
- `assets/` — пять скриншотов, использованных в инструкции;
- `.nojekyll` — служебный файл для GitHub Pages.

## Как бесплатно выложить сайт на GitHub (без командной строки)

1. Создайте аккаунт или войдите на **https://github.com/**.
2. Нажмите на **+** справа сверху → **New repository** (Новый репозиторий).
3. Назовите репозиторий **`instrukciya-zakazy`** (можно выбрать другое название). Выберите **Public** — это необходимо для GitHub Pages на бесплатном плане. Нажмите **Create repository**.
4. Распакуйте ZIP-архив с этим сайтом на компьютере. Откройте полученную папку. Там должны быть `index.html`, `styles.css`, `theme-reference.css`, `app.js`, папка `assets`, `README.md` и `.nojekyll` (скрытый файл может не отображаться — ничего страшного).
5. На странице созданного репозитория выберите **uploading an existing file** (или **Add file → Upload files**). **Перетащите файлы и папку `assets` из распакованной папки** в окно загрузки. Важно, чтобы `index.html` оказался в корне репозитория, а не внутри дополнительной вложенной папки.
6. Нажмите **Commit changes** (Сохранить изменения).
7. В репозитории откройте **Settings → Pages**.
8. В блоке **Build and deployment** выберите **Source: Deploy from a branch**.
9. Выберите **Branch: main**, папку **/(root)** и нажмите **Save**.
10. После публикации сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/instrukciya-zakazy/`. Логин должен совпадать с вашим именем пользователя на GitHub. GitHub предупреждает, что публикация изменений может занять до 10 минут. Ссылку можно также найти через **Settings → Pages → Visit site**.

**Если сайт показывает 404:** проверьте, что `index.html` лежит в корне репозитория, выбрана ветка `main`, папка `/(root)`, и дождитесь завершения публикации.

## Как посмотреть сайт без GitHub

Распакуйте ZIP и дважды щёлкните `index.html`. Он откроется в вашем браузере. Интернет для просмотра текста и скриншотов не нужен; внешние Telegram-ссылки требуют подключения.

## Как редактировать

Чтобы изменить **текст или ссылки**, откройте `index.html` обычным текстовым редактором (например, VS Code). Чтобы заменить **скриншот**, положите новое изображение в `assets` и используйте то же имя или обновите адрес файла в `index.html`. Чтобы поменять **цвета**, измените переменные `:root` в начале `theme-reference.css`.

После правок загрузите изменённые файлы в тот же репозиторий (через `Add file → Upload files` и сохраните изменения). GitHub Pages обновит опубликованный сайт.

## Важное предупреждение о публичности

GitHub Pages обычно публикует сайт в открытом интернете. Не размещайте там реальные номера карт, реквизиты, имена клиентов, секретные ссылки, токены, личные платежные данные или конфиденциальные ID заказов. **В этой первой версии использованы присланные скриншоты; проверьте их и при необходимости обезличьте перед публикацией.** Даже приватный репозиторий не гарантирует приватность самого сайта GitHub Pages.

При обработке платежей сверяйте зачисления непосредственно в банковском приложении. Сайт предназначен для ознакомления, а не для обработки платежей.
